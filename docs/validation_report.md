## Notes from the job

- Synthetic demo data: every number comes from the mock data generator, not real weather. This is proxy validation on synthetic truth, not evidence of real-world skill.
- Evaluation window TEST 2024-07-17..2024-12-31, 164 issue dates, lead days 1-5, model s5-lgbm-9b632a7b1b. TEST first opened 2026-09-27T15:14:23 for this model version.
- Skill = 1 - score_model / score_baseline. 95% intervals from a moving-block bootstrap of daily errors (7-day blocks, 1000 resamples, seed 42). Win = whole MAE-skill interval above 0; loss = whole interval below 0; tie = interval contains 0. The model value is the reconciled mean; intervals are p10..p90 after conformal offsets.
- B0 = raw block forecast (mean of the two NWP sources) copied to every Panchayat; B1 = bias-corrected block forecast, which the model is reconciled to, so skill against B1 is what the Panchayat model itself adds; B2 = B1 plus lapse rate and station offsets.
