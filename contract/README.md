# contract/

The API contract shared by backend and frontend (Appendix A of the guides).

- `openapi.json`: generated by the backend (`python -m gramdrishti.export_openapi`). Do not edit by hand.
- `examples/*.json`: one example response per endpoint, validated against the backend models. The frontend serves these as its mock API.
- `CHANGELOG.md`: every contract version and what changed.
- `snapshot/` (later, S12): exported responses for offline demo mode.

Changes go through a pull request that both people read. See `CONTRIBUTING.md`.
